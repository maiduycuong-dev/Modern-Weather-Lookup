This is a lightweight weather application that uses only the front-end and is built as a static website. Here is what you need to know about it:
1.Overview:
Allows users to search for cities and displays current weather information:
- Uses Open-Meteo APIs:
- Geocoding API to locate the city.
- Forecast API to retrieve data on temperature, humidity, wind speed, and weather condition codes.
2.The website displays the following information:
- City name
- Local time
- Current temperature
- Weather description
- Humidity and wind speed
- Option to toggle temperature units (°C/°F)
3.Repository structure:
- index.html: Application structure and user interface (UI) layout.
- style.css: Design style inspired by glassmorphism/Fluent design, featuring gradients, a card-based layout, a settings panel, and a responsive design.
- script.js: All interaction logic, API calls, options for UI/fonts/units, and local time display functionality.
- favicon.png: Application icon (Source: Icons8.com).
- LICENSE: MIT license for the website.
4.Conclusion this Project:
This is a continuously updated "demo"—a project of moderate scale. If you are not entirely satisfied and wish to customize the application, feel free to "fork" the project, as it is open-source. Thank you for reading this "README.md" file, and I wish you good health!
